## Habilidades e estilo de jogo

| Círculo | Habilidade | Função resumida |
| --- | --- | --- |
| C1 | Arrest | Imobiliza inimigos com uma amarra. |
| C1 | Repair | Abre uma loja de reparo de equipamentos. |
| C1 | Weapon Maintenance | Serviço que melhora temporariamente o ataque de armas. |
| C1 | Armor Maintenance | Serviço que melhora temporariamente a defesa de equipamentos. |
| C2 | Base Camp | Monta acampamento com armazenamento, transporte e suporte. |
| C2 | Refreshment Table | Prepara comidas de reforço junto ao acampamento. |
| C3 | Penalty Reduction | Reduz penalidades de ficar incapacitado. |

Fonte das habilidades: [F46](../../fontes.md#f46), captura de **2016-04-01**. Os resumos são editoriais e não substituem testes no cliente. O banco contém descrições, não uma garantia de todos os efeitos implementados naquele patch.

## Recorte e versão solo

Esta ficha de panorama inclui os círculos compatíveis com o limite de **Rank 7**, com classes ocultas em C1. Não introduzimos habilidades de círculos de expansão posterior. Nomes históricos foram preservados, inclusive quando a grafia difere de guias ou versões mais novas.

A adaptação solo **removerá classes mágicas**. Esta página preserva o original para consulta; a seleção nominal e o tratamento de híbridos estão nas [diretrizes do projeto](../../projeto-solo/diretrizes.md).
