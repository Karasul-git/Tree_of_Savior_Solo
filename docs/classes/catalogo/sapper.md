## Habilidades e estilo de jogo

| Círculo | Habilidade | Função resumida |
| --- | --- | --- |
| C1 | Stake Stockades | Armadilha de estacas que fere ao contato. |
| C1 | Conceal | Esconde uma armadilha preparada. |
| C1 | Claymore | Instala explosivo acionado ao reutilizar a habilidade. |
| C1 | Punji Stake | Armadilha que arremessa inimigos para longe. |
| C1 | Detonate Traps | Explode armadilhas e círculos mágicos próximos. |
| C2 | Broom Trap | Armadilha giratória que atinge uma área. |
| C2 | Collar Bomb | Prende bomba que explode ao contato com outro inimigo. |
| C3 | Spike Shooter | Armadilha de fio que dispara flechas. |

Fonte das habilidades: [F70](../../fontes.md#f70), captura de **2016-04-05**. Os resumos são editoriais e não substituem testes no cliente. O banco contém descrições, não uma garantia de todos os efeitos implementados naquele patch.

## Recorte e versão solo

Esta ficha de panorama inclui os círculos compatíveis com o limite de **Rank 7**, com classes ocultas em C1. Não introduzimos habilidades de círculos de expansão posterior. Nomes históricos foram preservados, inclusive quando a grafia difere de guias ou versões mais novas.

A adaptação solo **removerá classes mágicas**. Esta página preserva o original para consulta; a seleção nominal e o tratamento de híbridos estão nas [diretrizes do projeto](../../projeto-solo/diretrizes.md).
