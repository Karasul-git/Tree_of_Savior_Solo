## Habilidades e estilo de jogo

| Círculo | Habilidade | Função resumida |
| --- | --- | --- |
| C1 | Gather Corpse | Recolhe cadáveres como recurso. |
| C1 | Create Shoggoth | Cria uma criatura a partir de cartas do Necronomicon. |
| C1 | Flesh Cannon | Bombardeia uma área com partes de cadáveres. |
| C1 | Flesh Hoop | Partes de cadáveres orbitam o usuário e causam dano. |
| C1 | Dirty Pole | Ergue restos mortais que deterioram inimigos próximos. |
| C2 | Disinter | Recolhe restos onde um inimigo morreu. |
| C2 | Corpse Tower | Constrói uma torre ofensiva feita de cadáveres. |
| C2 | Raise Dead | Invoca soldados esqueletos que seguem e combatem. |

Fonte das habilidades: [F62](../../fontes.md#f62), captura de **2016-04-01**. Os resumos são editoriais e não substituem testes no cliente. O banco contém descrições, não uma garantia de todos os efeitos implementados naquele patch.

## Recorte e versão solo

Esta ficha de panorama inclui os círculos compatíveis com o limite de **Rank 7**, com classes ocultas em C1. Não introduzimos habilidades de círculos de expansão posterior. Nomes históricos foram preservados, inclusive quando a grafia difere de guias ou versões mais novas.

A adaptação solo **removerá classes mágicas**. Esta página preserva o original para consulta; a seleção nominal e o tratamento de híbridos estão nas [diretrizes do projeto](../../projeto-solo/diretrizes.md).
