## Habilidades e estilo de jogo

| Círculo | Habilidade | Função resumida |
| --- | --- | --- |
| C1 | Simony | Transforma habilidades permitidas em pergaminhos utilizáveis por outros. |
| C1 | Indulgentia | Ritual que remove estados negativos aliados ou causa dano. |
| C1 | Discerning Evil | Prolonga efeitos negativos sobre o alvo. |
| C1 | Increase Magic Defense | Aumenta temporariamente a defesa mágica do grupo. |
| C2 | Oblation | Abre uma caixa de oferendas para receber itens. |
| C2 | Spell Shop | Abre uma loja para vender efeitos benéficos. |
| C3 | Decatose | Usa dinheiro num ataque com chance de execução. |

Fonte das habilidades: [F87](../../fontes.md#f87), captura de **2016-03-31**. Os resumos são editoriais e não substituem testes no cliente. O banco contém descrições, não uma garantia de todos os efeitos implementados naquele patch.

## Recorte e versão solo

Esta ficha de panorama inclui os círculos compatíveis com o limite de **Rank 7**, com classes ocultas em C1. Não introduzimos habilidades de círculos de expansão posterior. Nomes históricos foram preservados, inclusive quando a grafia difere de guias ou versões mais novas.

A adaptação solo **removerá classes mágicas**. Esta página preserva o original para consulta; a seleção nominal e o tratamento de híbridos estão nas [diretrizes do projeto](../../projeto-solo/diretrizes.md).
