## Habilidades e estilo de jogo

| Círculo | Habilidade | Função resumida |
| --- | --- | --- |
| C1 | Arcane Energy | Aumenta SP e stamina máximos do grupo. |
| C1 | Change | Troca o monstro por outro de nível semelhante. |
| C1 | Clairvoyance | Revela antecipadamente o item que o monstro deixará. |
| C1 | Counter Spell | Anula magia próxima ao usuário. |
| C1 | Forecast | Mostra onde os inimigos atacarão. |
| C1 | Resetting | Altera o item que um inimigo deixará. |
| C1 | Prophecy | Previne estados negativos de nível baixo no grupo. |
| C2 | Death Sentence | Condena o alvo à morte após uma espera. |

Fonte das habilidades: [F90](../../fontes.md#f90), captura de **2016-04-05**. Os resumos são editoriais e não substituem testes no cliente. O banco contém descrições, não uma garantia de todos os efeitos implementados naquele patch.

## Recorte e versão solo

Esta ficha de panorama inclui os círculos compatíveis com o limite de **Rank 7**, com classes ocultas em C1. Não introduzimos habilidades de círculos de expansão posterior. Nomes históricos foram preservados, inclusive quando a grafia difere de guias ou versões mais novas.

A adaptação solo **removerá classes mágicas**. Esta página preserva o original para consulta; a seleção nominal e o tratamento de híbridos estão nas [diretrizes do projeto](../../projeto-solo/diretrizes.md).
