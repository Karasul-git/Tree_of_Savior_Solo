## Como ler uma ficha

- **Documentado no período:** há relato ou guia contemporâneo que sustenta o ponto, com as limitações descritas nas fontes.
- **Conferência pendente:** falta confirmar círculo, funcionamento ou número na versão internacional de lançamento.
- **Imagem oficial; data visual pendente:** arquivo da desenvolvedora, ainda sem prova de que era idêntico em 2016.

As tabelas listam quando uma habilidade se tornava disponível, não seu nível máximo nem uma build recomendada. Não importamos os valores da base Melia/Laima para preencher lacunas históricas.
