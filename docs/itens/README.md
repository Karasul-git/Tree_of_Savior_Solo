# Equipamentos

2182 equipamentos: armas, escudos, armaduras e acessórios, do nível 1 ao 280. Cada item tem a sua página. Os valores são provisórios: vêm do jogo atual e ainda serão calibrados para o nosso.

**Grau:** o servidor organiza os equipamentos em linhas de grau (1 a 4). O grau 1 é a linha comum, e os maiores graus vêm mais fortes nos mesmos níveis.
