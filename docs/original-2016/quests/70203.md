## Início

> Assistant Commander Gorman is trying to give you the duty which Hix should've been responsible for. Talk with the Assistant Commander Gorman.

**Objetivo:** Talk with the Mesafasla Assistant Commander Gorman

## Durante

> When you activate one of the shrines of Romiva Magic Fields, one other shrine will also react. Use it to activate the shrine which Gormen has told you. If you forgot to which shrine to activate, check the memo which Gormen has given to you. The memo can only be checked when you activate the shrine.

**Objetivo:** Activate only the designated shrines

## Fim

> You've succeeded activating Romuva magic circle. Tell this to Gorman.

**Objetivo:** Talk with the Mesafasla Assistant Commander Gorman
