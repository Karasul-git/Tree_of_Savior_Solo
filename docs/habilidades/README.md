# Habilidades

As habilidades das **39 classes** do jogo, nas três bases (Warrior, Archer e Scout): **266 habilidades**, cada uma com a sua página. Escolha uma classe para ver as habilidades dela.

**Situação das habilidades:** *No jogo* são as que entram na classe; *Em revisão* ainda podem mudar ou sair. **A pontuação (dano, custo e recarga) é provisória** e vai mudar na calibragem.
